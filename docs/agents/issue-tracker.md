# Issue Tracker

## Tracker

This repository uses local markdown issues.

Issues live under:

```text
.scratch/<feature>/
```

Each feature directory may contain:

- `issue.md` or another descriptive issue file
- implementation notes
- decision records
- validation results
- links to related work

## Workflow

Use local markdown files for planning and tracking work. Do not assume GitHub, GitLab, Jira, Linear, or another hosted tracker is configured.

A local issue should identify:

- Problem or requested outcome
- Scope and non-goals
- Acceptance criteria
- Dependencies
- Validation approach
- Current status
- Related documents or ADRs

The local tracker is intentionally compatible with solo development and offline hardware work.

## Pull requests

Pull requests are not currently configured as an issue intake surface.
